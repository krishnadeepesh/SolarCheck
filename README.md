# SolarCheck – IoT-Based Solar Power Monitoring System

SolarCheck is an IoT-based solar power monitoring system that measures the voltage, current, and power generated by a solar panel. It uses an ESP32 microcontroller and an INA219 sensor to collect electrical measurements and transmit them over Wi-Fi to a Django backend. The readings are stored in a database and displayed through a web dashboard.

## Project Overview

The system monitors the electrical output of a solar panel and allows users to view the collected readings through a web-based dashboard.

### Key Features

- Measures solar panel voltage and current.
- Calculates power generated by the solar panel.
- Uses ESP32 for sensor data collection and Wi-Fi communication.
- Sends readings to a Django REST API using HTTP POST requests.
- Stores sensor readings in an SQLite database.
- Displays monitoring data through a web dashboard.
- Uses Docker for application containerization.
- Deployed on Render for remote access.

## Circuit Connections

### INA219 to ESP32

| INA219 Pin | ESP32 Pin |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

### Solar Panel and Load Connections

1. Solar panel positive (+) → INA219 VIN+
2. INA219 VIN− → Load resistor
3. Other end of the load resistor → Common GND
4. Solar panel negative (−) → Common GND

## System Architecture

The system follows this data flow:

```text
Solar Panel
     |
     v
INA219 Sensor
     |
     v
ESP32 Microcontroller
     |
     | Wi-Fi / HTTP POST
     v
Django Backend API
     |
     v
SQLite Database
     |
     v
Web Dashboard
```

## Working Principle

1. The solar panel generates electrical energy when exposed to light.
2. The INA219 sensor measures voltage and current.
3. The ESP32 reads the sensor measurements through the I2C communication protocol.
4. The ESP32 calculates the power using voltage and current.
5. The readings are transmitted to the Django backend through a Wi-Fi connection.
6. Django receives the data through an API endpoint and stores it in the SQLite database.
7. The dashboard displays the collected solar panel readings.

**Power Calculation:**

Power is calculated by multiplying voltage and current.

```text
Power (W) = Voltage (V) × Current (A)
```

## Local Setup

### 1. Clone the Repository

```bash
git clone https://github.com/krishnadeepesh/SolarCheck.git
```

### 2. Navigate to the Project Directory

```bash
cd SolarCheck
```

### 3. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 4. Apply Database Migrations

```bash
python manage.py migrate
```

### 5. Start the Django Development Server

```bash
python manage.py runserver
```

Open the following address in your browser:

```text
http://127.0.0.1:8000/
```

## ESP32 Configuration

1. Open the ESP32 program in Arduino IDE.
2. Install the required ESP32 board package and Adafruit INA219 library.
3. Update the Wi-Fi credentials in the program.
4. Set the API URL to the deployed Django endpoint.

```cpp
const char* serverURL = "https://solarcheck-qcjf.onrender.com/api/reading/";
```

5. Select the correct ESP32 board and COM port.
6. Upload the program to the ESP32.
7. Open Serial Monitor at 115200 baud to view sensor readings and server responses.

## API Endpoint

The Django backend provides an API endpoint for receiving sensor readings.

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/reading/` | Receives and stores sensor readings |

Example JSON data:

```json
{
  "voltage": 5.2,
  "current": 0.15
}
```

The backend calculates power and stores the reading in the database.
